Vacation Planner

An Android app for travel agents to manage client vacations and excursions. Agents can add, edit, and delete trips, search their bookings, and generate a report of current and past vacations.

Download

Download the APK

Requires Android 8.0 or later.

Install

  1. Tap the download link on your Android device.
  2. Open the downloaded file.
  3. Allow installation from this source when prompted, then open the file again.
  4. Tap Install, then Open.

First Launch

The app has no accounts to start with. Tap Create Account on the sign-in screen. Passwords must be at least 8 characters and include an uppercase letter, a number, and a symbol.
